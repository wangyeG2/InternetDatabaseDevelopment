## 实际浏览器检查

通过后台页面登录管理员，填写新闻表单并保存草稿，确认前台访问为 404；依次点击发布、撤回、再次发布、删除，分别确认前台为 200、404、200、404。正文包含的测试脚本文本被转义。另使用普通成员账户验证后台登录拒绝。

浏览器实际发送 GET 发布请求得到 405，携带登录会话但缺少 CSRF 的 POST 得到 400。没有关闭 CSRF 机制。浏览器检查未发现页面脚本异常。

390 像素宽度下检查公开列表、详情、后台编辑及后台列表。后台表格在自身容器中横向滚动，页面整体宽度不被撑开。测试记录见 `evidence/browser-checks.json`，九张页面截图见同目录。截图保留开发环境原有导航和调试工具条。

## 数据库还原与示例命令

从干净迁移结果导出 `data/install.sql`，仅包含表结构、三条默认分类和迁移版本记录。另建空库导入后，业务表为六张：用户表及五张新闻表；另有一张迁移记录表。用户、新闻、标签、关联和历史记录均为空。

导入后再次运行迁移，得到“无新迁移”。核对 `news.content`、`news_revision.snapshot` 均为 `MEDIUMTEXT`。还原详情见 `evidence/sql-restore-checks.json`。

开发库使用私人测试账号运行 `php yii news/seed 实际用户名`，连续执行两次，新闻数均为 3、标签数均为 5、关联数均为 5、历史数均为 3。安装 SQL 不包含这些账号或示例新闻。

## 源码包和网页下载

执行 `python tools/package_b.py`，验证 ZIP CRC，并检查包内包含安装 SQL、公开环境模板和本项目源码，不包含第三方依赖、初始化后的本地配置、运行缓存、个人作业或重复源码包。另检查包中没有本次私人预览账号口令。

通过前台下载页面找到团队源码包，实际发送 GET 与 HEAD，均返回 200；GET 响应是 ZIP 附件，HEAD 长度与实际文件一致，下载内容的 SHA256 与本地源码包一致。最终校验值随 `data/team/B_news_source.zip.sha256` 提供，重新打包会更新校验值。

## 验收范围

本次证明 B 模块与当前基线可以在本机独立运行，不代替全组集成验收。团队展示、留言板、动态图形和最终至少十一张业务表仍需其他成员接入后检查。未验证真实 SMTP 投递、多机器部署、性能压测或完整权限管理后台。

Tower 尚无账号，用户选择先保留可录入清单，因此没有线上看板截图。个人作业目录尚无成员提供的真实 ZIP，不将测试生成的临时 ZIP 当作个人交付；测试结束后临时文件已清理。
