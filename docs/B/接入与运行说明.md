# B 模块接入与运行说明

本文提供 B 模块的接入步骤，团队正式部署文档由 A 汇总。命令以仓库根目录及 `advanced` 目录为准；实际 PHP、Composer 和 MySQL 程序路径可按本机环境调整。

## 合并时检查

本地分支为 `feature/b-news`，基线为 `642f359`。共享变更包括 `user.role`、RequestForm、后台统一管理员检查、前后台导航入口、数据库模板 utf8mb4、Composer PHP 最低版本及 PHP 换行约定。A/C 合并其正在维护的用户和布局代码时，应保留相应接入点。

新闻正文按纯文本存储和显示；其他成员如调用公开新闻，统一使用 `News::find()->publiclyVisible()`。具体路由、权限、参数与视图变量见[接口约定](接口与路由约定.md)。

## 首次启动

要求 PHP 8.3 或以上，实际验证为 PHP 8.4.27、MySQL 8.0.45。启用 `pdo_mysql`、`mbstring`、`intl`、`openssl`、`fileinfo` 等框架依赖扩展。依赖恢复使用仓库锁文件：

```text
cd advanced
composer install
```

全新解压且尚未初始化的目录执行：

```text
php init --env=Development
```

已有环境不重复初始化，直接保留本机配置。开发环境的数据库连接填写在 `advanced/common/config/main-local.php`，数据库名称和密码不得提交。

数据库安装选择以下一种方式：

1. 新建空数据库后运行 `php yii migrate --interactive=0`，将应用全部迁移和默认分类。
2. 将仓库根目录 `data/install.sql` 导入另一个空数据库，然后运行同一迁移命令，正常结果为无新迁移。

现有数据库升级仅运行迁移，不导入初始 SQL。当前 SQL 是 B 模块快照，A 集成其他成员数据库迁移后应重新导出全组版本。

前后台分别启动，示例命令在两个终端执行：

```text
php -S 127.0.0.1:8080 -t frontend/web
php -S 127.0.0.1:8081 -t backend/web
```

前台入口为 `http://127.0.0.1:8080/index.php?r=news/index`，后台为 `http://127.0.0.1:8081/index.php?r=news/index`。这是本地开发方式；正式服务器应分别把文档根目录指向两个 `web` 目录。

## 管理员和示例数据

由 A 的账号流程创建并激活一个账户，再在 `advanced` 执行：

```text
php yii access/grant-admin 实际用户名
php yii news/seed 实际用户名
```

授权命令只接受已有激活账号，不自动注册、激活或修改密码。安装 SQL 没有默认账号。示例命令可选，生成两条已发布内容和一条草稿；按固定标识跳过已有示例，重复执行不会新增相同记录。示例均带明确标注，不作为真实赛事或活动安排。

本机验证账号的口令只保存在 E 盘私人测试目录中，不随源码包提供。其他成员应使用自己的账号。

## 执行检查

测试必须使用独立数据库。在 `advanced/common/config/test-local.php` 填写专用测试库连接，测试库名称应包含 `test`。新闻集成夹具会清理测试库中的用户和新闻数据，禁止连接开发库或正式库。

```text
php yii_test migrate --interactive=0
php vendor/bin/codecept build
php vendor/bin/codecept run --env php-builtin
php vendor/bin/phpstan analyse --memory-limit=512M
php vendor/bin/phpcs
composer validate --strict --no-check-publish
```

测试环境会临时使用 38091、38092 端口启动 PHP 服务。PHP 必须能通过 PATH 被测试子进程找到，子进程需使用相同扩展配置。当前结果和边界见[集成测试报告](集成测试报告.md)。

## 源码包与作业下载

从仓库根目录执行：

```text
python tools/package_b.py
```

输出为 `data/team/B_news_source.zip` 和同名 `.sha256` 校验文件。工具依赖 Git 工作目录和 Python 标准库，不需要额外 Python 包。源码 ZIP 中没有 `.git`，从 ZIP 解压的副本可以运行网站；重新生成交付包应回到 Git 工作目录执行该脚本。

工具排除 `advanced/vendor/`、实际 `*-local.php`、运行缓存、已发布静态资源缓存及两类已有作业包，保留 `advanced/environments/` 中的公开配置模板。恢复依赖后再初始化环境。

前台 `download/index` 显示 `data/team/`、`data/personal/` 顶层的 ZIP。团队源码包已经提供；各成员真实个人作业 ZIP 由本人补充，随后页面自动出现对应链接。当前课程源码包仅含基线与 B 实现，全组完成后应重新打包。
