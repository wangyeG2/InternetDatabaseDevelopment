# 新闻公告模块接口与路由约定

本约定由 B 根据当前 Yii2 Advanced 基线先行确定，供其他模块集成。前后台是两个独立应用，均沿用 `index.php?r=控制器/动作` 的默认路由，不要求 URL 重写。

## 访问权限

`user.role` 为 `member` 或 `admin`。注册用户和原有用户默认 `member`，不会自动升级。管理身份还要求账号状态为激活。首次授权通过命令 `php yii access/grant-admin <用户名>` 完成，命令仅接受已激活账号，不修改密码和激活状态。

后台应用通过 `backend/components/AdminAccess.php` 统一拦截管理路由，登录、错误和退出路由由原有控制器规则处理。普通用户的后台登录请求返回表单错误；已有普通用户会话直接访问管理功能时返回 403。未登录用户跳转后台登录页。

## 路由表

| 应用 | 路由 | 方法 | 权限 | 参数与结果 |
| --- | --- | --- | --- | --- |
| 前台 | `news/index` | GET | 公开 | `q`、`category`、`tag`、`page`、`sort`；分页列表 |
| 前台 | `news/view` | GET | 公开 | `id`；未公开内容及不存在 ID 返回 404 |
| 前台 | `download/index` | GET | 公开 | 团队和个人 ZIP 下载列表 |
| 前台 | `download/file` | GET HEAD | 公开 | `group=team/personal`、64 位十六进制 `id`；仅固定目录 ZIP |
| 后台 | `news/index` | GET | 管理员 | 同前台筛选，另有 `status`，默认排除软删除新闻 |
| 后台 | `news/view` | GET | 管理员 | `id`；详情和分页修改记录，允许查看删除后的记录 |
| 后台 | `news/create` | GET POST | 管理员 | `NewsForm[...]`；成功后跳转详情 |
| 后台 | `news/update` | GET POST | 管理员 | `id` 和 `NewsForm[...]`；成功后跳转详情 |
| 后台 | `news/publish` | POST | 管理员 | `id`；发布 |
| 后台 | `news/withdraw` | POST | 管理员 | `id`；撤回为草稿 |
| 后台 | `news/delete` | POST | 管理员 | `id`；软删除，保留历史 |
| 后台 | `news-category/index` | GET | 管理员 | 分类列表 |
| 后台 | `news-category/create` | GET POST | 管理员 | `NewsCategoryForm[...]` |
| 后台 | `news-category/update` | GET POST | 管理员 | `id` 和 `NewsCategoryForm[...]` |

发布、撤回和删除不接受 GET，请求返回 405。POST 使用 Yii 默认 CSRF 机制，不关闭应用的 CSRF 保护。

## 新闻表单

| 字段 | 约束 |
| --- | --- |
| `title` | 必填，最多 180 字符 |
| `content` | 必填，最多 50000 字符，纯文本保存与转义显示 |
| `summary` | 可选，最多 360 字符 |
| `category_id` | 必须指向实际分类 |
| `status` | `0` 草稿、`10` 发布、`20` 归档 |
| `is_pinned` | `0` 普通、`1` 置顶 |
| `slug` | 可选，最多 96 字符；小写字母、数字、连字符；为空则自动生成 |
| `tags` | 英文或中文逗号分隔；去重并统一小写，最多 10 个，每个最多 32 字符 |

作者、创建和修改时间、发布时间、删除时间均由服务端维护。更新不会改变原作者，修改人另记入 `news_revision`。正文不执行 HTML，也不引入富文本插件。

## 共享模型与视图变量

- 共享模型位于 `advanced/common/models/News*.php`；后台表单位于 `backend/models`；事务服务位于 `backend/services/NewsService.php`。
- 前台公开条件必须统一调用 `News::find()->publiclyVisible()`，同时要求已发布、未删除、发布时间不晚于当前时间、分类启用。不要自行省略其中条件。
- 前台列表变量：`search`、`dataProvider`、`categories`；前台详情变量：`news`。
- 后台列表变量同前台；编辑变量：`model`、`categories`；后台详情：`news`、`history`。
- 新闻样式通过独立 NewsAsset 加载，避免覆盖 C 后续维护的共享布局。
- 新闻时间存为 Unix 秒，页面显示跟随 Yii 应用时区。

## 数据库及下载边界

五张新闻表由 B 维护，与现有 `user.id` 关联。用户停用应优先采用状态变更；已有作者或修改记录关联时，外键会阻止直接删除用户。分类采用停用方式维护关联完整性。

数据库连接模板改用 utf8mb4，新增新闻表也使用 utf8mb4。新增迁移不自动插入管理账号或默认密码。

作业下载只公开放入仓库根目录 `/data/team/` 与 `/data/personal/` 的 ZIP；不允许把本地配置或未授权材料放入这两个公开目录。当前个人作业 ZIP 尚未补充，页面如实显示尚未上传。
