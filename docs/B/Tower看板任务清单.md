## 录入顺序和协作依赖

建立账号后创建团队与看板项目，依次新建上面的十张任务卡，负责人先选择真实 B 账号。B01—B07、B09、B10 的本地交付已就绪，B08 的本地验证已完成；由于尚未推送和发起 PR，录入时仍放在“开发中”，描述中注明“本地验证完成，待提交评审”。

后续创建真实 PR 后移到“待评审”，将 PR 链接和 `docs/B/gitlog.txt` 对应提交填入卡片。返修时记录实际问题，合并后再移到“已完成”。

另建立三项联调任务：A 合并管理身份、数据库迁移和空库安装 SQL；C 合并共享导航入口并提供团队展示页面；D 接入留言板和动态图形后共同复查前后台流程。由对应成员确认负责人和截止时间，本清单不代填其工作完成情况。
