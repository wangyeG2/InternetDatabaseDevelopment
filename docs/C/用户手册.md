# 2026世界杯主题团队主页用户手册（草稿）

编写范围：C 赵非凡的团队展示/编辑与共享导航；基线已有 B 新闻公告和作业下载。自动测试与本机 HTTP 验收记录见 evidence/NOTES.md。本文只描述已实现功能，不代表全组项目完成。

## 游客浏览

1. 打开前台 `index.php?r=site/index`，从首页进入“团队介绍”或“成员”。“成员”定位团队页成员区。
2. 团队页显示当前团队介绍、公开成员、项目时间线和相关链接。没有资料时如实显示尚未发布/暂无内容。
3. 点击成员姓名进入 `index.php?r=team/member&slug=成员标识`，阅读个人介绍与职责分工。隐藏或不存在成员返回404。
4. “新闻公告”与“作业下载”为已集成的 B 功能；下载页只列出当前提供的作业包。详见 docs/B 文档。示例内容不能作为真实比赛结果或已完成项目事实。
5. 导航保留注册、登录、退出及色彩模式按钮；游客不能编辑团队资料。

## 管理员进入后台

账号注册、激活等由 A 的流程负责。已有激活账号后，由有服务器命令权限的维护者在 advanced 运行：

```text
php yii access/grant-admin 实际用户名
```

该命令沿用 B，不创建账号、不修改口令。不要把账号或口令写入仓库。打开后台 `index.php?r=site/login`，用自己的管理员账号登录。前后台会话独立。普通成员不能通过后台登录取得管理权限；已有普通成员会话访问团队管理返回403。

## 编辑资料

- “团队资料”：填写名称、唯一slug、口号、摘要、正文、主题说明后保存。首次保存创建当前资料，之后修改同一份。slug例子 `course-team`。
- “成员管理”：新增或修改姓名、唯一slug、模块A/B/C/D（可空）、角色、主要职责、个人介绍。显示顺序越小越靠前。公开选择“是”才可被游客查看。
- 额外职责每行填写 `标题 | 说明`，最多30行。保存会整体替换该成员原有职责；清空表示移除额外职责。成员和职责一起保存。
- “项目时间线”：填写标题、日期（如2026-11-28）、说明、是否示例与公开状态。项目计划应明确写“计划”，示例应选择“是”；不要把赛事结果当作课程节点。
- “相关链接”：填写名称和完整http/https网址，选择公开后出现在前台。
- 列表“隐藏”会经确认提交POST，保留记录供以后编辑；重新公开请修改“公开”为“是”并保存。

成功时显示“团队数据已保存。”并返回列表；隐藏时显示“已隐藏，数据保留。”。没有提供照片上传、账号绑定或物理删除功能。

## 错误与权限

必填字段、长度、唯一slug、日期、网址、0/1公开值和排序范围均验证；错误留在表单显示，不保存该次修改。正文、个人介绍是纯文本，HTML只作为文字显示。缺失记录404；直接GET隐藏接口405；缺少有效CSRF令牌的POST返回400。若页面过期导致令牌错误，重新打开编辑页再提交。

## 数据与协作状态

现有数据库只运行 `php yii migrate --interactive=0` 升级；禁止重新导入安装快照覆盖数据。维护者可选运行 `php yii team/seed` 补充带“示例”标记的展示资料，不创建用户，重复执行按稳定标识跳过已有内容；修改了示例标识后不再视为同一示例。
