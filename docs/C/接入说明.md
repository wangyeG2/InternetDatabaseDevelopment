## 数据库

要求 PHP 8.3 或以上、按仓库锁文件安装依赖、MySQL 8（或兼容的 MariaDB）、utf8mb4。沿用各人已有的本机配置，不要把 `*-local.php` 或口令提交进仓库。已有数据库只运行迁移，不要重新导入 `data/install.sql`（该文件仍是 B 的空库快照，本次未改）：

```text
cd advanced
composer install
php yii migrate --interactive=0
```

迁移只新增五张团队表，不创建账号或密码。全新空库优先直接运行全部迁移。可选 `php yii team/seed`：按示例 slug、节点标题/日期、链接 URL 判断，已有行不覆盖。示例简介和计划均标明示例；四名成员使用真实姓名和分工，无虚构学号或邮箱；不创建用户。
