# C 接口与视图变量约定

前后台是独立 Yii 应用，使用 `index.php?r=controller/action`，不要求重写。所有请求保留 Yii 默认 CSRF。团队内容为纯文本，视图用 Html::encode 显示，CSS 保留换行。

## 路由与权限

| 应用 | 路由 | 方法 | 参数 / 行为 |
| --- | --- | --- | --- |
| 前台 | team/index | GET | 当前资料、公开成员、时间线和链接 |
| 前台 | team/member | GET | 必填 slug；不存在或隐藏返回404 |
| 后台 | team-profile/index | GET | 资料列表 |
| 后台 | team-profile/update | GET POST | 编辑当前资料；无资料则创建；不接收 id |
| 后台 | team-member/index | GET | 成员分页列表，每页20条 |
| 后台 | team-member/create、update | GET POST | update 必填整数 id；TeamMemberForm 字段 |
| 后台 | team-milestone/index、create、update | GET / GET POST / GET POST | update 必填整数 id；TeamMilestoneForm 字段 |
| 后台 | team-link/index、create、update | GET / GET POST / GET POST | update 必填整数 id；TeamLinkForm 字段 |
| 后台 | team-member/hide、team-milestone/hide、team-link/hide | POST | 整数 id；仅将 is_public 设为0，GET返回405 |

后台全部沿用应用级 AdminAccess：未登录跳转登录，已登录普通成员403；管理员还须账号激活。POST 缺失/非法 CSRF 返回400。创建/更新仅在 POST 且表单加载成功时保存，成功 flash 并跳转列表；非法字段留在表单显示错误。缺失记录404。没有物理删除接口。列表/前台拒绝非GET方法。

## 表单字段

各表单继承 TeamForm → B 的 RequestForm，拒绝数组、对象、null等非标量输入。字段先转字符串，保存时去除首尾空白。仅安全字段可赋值，不接收 id、user_id、updated_by、时间戳或 is_current。

| 表单 | 字段与限制 |
| --- | --- |
| TeamProfileForm | name必填120、slug必填80且唯一；motto180、summary500、body12000、theme_note500 |
| TeamMemberForm | name必填60、slug必填80且唯一；module_code为空或A/B/C/D，role_title120、duty255、bio12000；sort_order、is_public；duties最多30行/20000字符，每行 `标题 | 说明`，标题必填120、说明1000 |
| TeamMilestoneForm | title必填180、happened_on必填真实 YYYY-MM-DD 日期、summary1000、is_example、sort_order、is_public |
| TeamLinkForm | label必填120、url必填2048且仅http/https；sort_order、is_public |

slug 只接受小写字母、数字和单个连字符分隔的片段。长度均为字符数。sort_order 必填整数 -32768..32767；布尔字段必填且严格为0/1；非法值不会转换成真。表单未传字段在更新时保留原值。职责文本是替换式编辑，事务中保存成员并替换其职责，失败整体回滚。不要在职责标题/说明内使用 `|` 或换行作为内容。TeamService 再检查当前激活管理员，防止内部误调用。

## 视图变量与查询规则

| 视图 | 变量 |
| --- | --- |
| frontend/site/index | profile：TeamProfile或null |
| frontend/team/index | profile：TeamProfile或null；members：TeamMember[]；milestones：TeamMilestone[]；links：TeamLink[] |
| frontend/team/member | member：公开TeamMember，预载duties关系 |
| backend/team-*/index | dataProvider：ActiveDataProvider |
| backend/team-*/edit | model：对应Team*Form，包含record和验证错误 |

`TeamProfile::current()` 使用 `is_current=1`；数据库唯一索引加 CHECK 保证最多一条当前记录，非当前存 NULL。后台只编辑当前记录，不提供切换历史资料功能。

成员、节点、链接公开查询统一使用 `::find()->publiclyVisible()->ordered()`：is_public=1，sort_order升序、id升序；个人详情额外按slug筛选。TeamMember::getDuties() 按sort_order、id排序。职责必须随公开成员展示，不能独立开放查询端点。TeamQuery 的 publiclyVisible 仅适用于成员、节点、链接，不用于 profile/duty。

## A/B/D 集成点与边界

- A：保留账号与激活流程、AdminAccess、user.role；C 不创建用户/默认密码、不接管部署。user_id 可空且本期表单不绑定账号；updated_by由服务器写入。
- B：保留新闻公告、作业下载入口及 NewsAsset，不改变新闻/下载业务。首页不复制新闻查询规则。
- D：留言板/动态图形待集成，当前导航没有这些路由；D 应另行约定变量、权限和独立资源，不覆盖 TeamAsset/NewsAsset。
- C：共享导航/页脚/首页、五张团队表、团队公开页/后台编辑、独立TeamAsset、文档。体育主题只体现展示语言，不记录或虚构真实赛果。
- 共有前后台布局保留色彩模式切换与退出的POST行为。应用显示名在common/config/main.php设置。新样式在common/assets/team/team.css，由 common/assets/TeamAsset.php 发布 common/assets/team/team.css，前后台共用。
