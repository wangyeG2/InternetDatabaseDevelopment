# 代码规范与 PHP 文件注释头模板

## 命名与目录

- Controller 放在 `frontend/controllers` 或 `backend/controllers`，类名使用 PascalCase 并以 `Controller` 结尾。
- ActiveRecord 放在 `common/models`；应用专属表单和搜索模型放在对应应用的 `models` 目录。
- View 按控制器名放在 `views/<controller>/`，文件名使用小写动作名。
- CSS、JavaScript 和图片放在对应应用 `web/` 下；跨前后台共享的资源放在 `common/assets/`。
- 数据库结构变更必须创建 `console/migrations/` 迁移；新增索引和外键应与设计文档同步。
- 数据库字段使用 snake_case；PHP 类和方法使用 PascalCase/camelCase；常量使用全大写下划线。

## MVC 边界

- Model / Form 负责数据结构、验证和业务规则，不输出 HTML。
- Controller 负责请求、权限、调用模型并返回 View，不直接拼装 HTML。
- View 只渲染 Controller 传入的数据，不查询数据库或执行权限判断。
- 请求表单继承 `common\models\RequestForm`，以限制非标量请求值。
- 所有管理写操作使用 POST 并保留 Yii CSRF 保护；权限由应用级 `AdminAccess` 统一控制。

## PHP 文件要求

- 使用 `declare(strict_types=1);`，保持 UTF-8 编码。
- 新增 PHP 文件应包含用途及维护者注释头、命名空间、必要的类型声明。
- 数据库凭据只能放在被忽略的本地配置中，不得写入版本控制。
- 不在 View 中输出未经 HTML 编码的用户输入。

## PHP 注释头模板

```php
<?php

/** Briefly describe this file. Maintainer: A. */

declare(strict_types=1);

namespace app\path;
```

对于 PHP View 文件，可在 `declare` 后用 `@var` 标注 Controller 传入变量：

```php
/** @var yii\web\View $this */
/** @var common\models\User $user */
```
