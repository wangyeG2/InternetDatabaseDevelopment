# 2026 世界杯主题团队主页：数据库设计与数据字典

版本日期：2026-11-18  
数据库：MySQL / XAMPP  
当前已集成业务表：11 张（用户 1 张、新闻 5 张、团队 5 张）

## 1. 数据库设计

项目采用 Yii2 ActiveRecord 与迁移管理数据库。所有时间字段均为 Unix 秒；新增业务表使用 InnoDB 和 `utf8mb4_unicode_ci`。用户表是认证身份表，新闻与团队资料通过外键引用用户。

```text
user 1 ─── N news (author_id)
user 1 ─── N news_revision (editor_id)
news_category 1 ─── N news
news 1 ─── N news_revision
news N ─── N news_tag (news_tag_link)

user 1 ─── N team_profile (updated_by)
user 1 ─── N team_member (user_id)
team_member 1 ─── N team_member_duty
```

`team_milestone` 和 `team_link` 是独立展示数据。用户和分类应采用停用状态保留历史关联；新闻采用软删除。`data/install.sql` 仅用于新建空库，已有数据库通过 `advanced/yii migrate` 升级。留言板及动态图形模块尚未合入本版本，最终交付前应将其迁移和字典补入。

## 2. 表清单

| 表 | 用途 | 主要约束 |
|---|---|---|
| `user` | 登录账号、角色及验证状态 | `username`、`email` 唯一 |
| `news_category` | 新闻分类 | `name`、`slug` 唯一 |
| `news` | 新闻内容 | `slug` 唯一；分类、作者外键 |
| `news_tag` | 新闻标签 | `name` 唯一 |
| `news_tag_link` | 新闻与标签关联 | `(news_id, tag_id)` 联合主键 |
| `news_revision` | 新闻操作历史 | 新闻、编辑用户外键 |
| `team_profile` | 团队介绍 | `slug` 唯一；最多一条 `is_current=1` |
| `team_member` | 团队成员 | `slug` 唯一；可选关联账号 |
| `team_member_duty` | 成员职责 | 关联 `team_member` |
| `team_milestone` | 项目时间线 | 公开状态及排序 |
| `team_link` | 团队相关链接 | 公开状态及排序 |

## 4. 索引与关联规则

- `news` 的公开列表按状态、软删除、置顶和发布时间筛选；分类与作者均有索引。
- 新闻和分类采用停用/软删除，保留新闻历史；用户不物理删除，避免破坏新闻和团队数据的外键。
- `news_tag_link` 以 `(news_id, tag_id)` 联合主键防止重复关联。
- `team_member`、`team_milestone`、`team_link` 按公开状态和排序字段建索引；职责按成员和排序字段建索引。
- `team_profile.is_current` 的唯一索引允许多条 NULL，但最多一条值为 1。
- 业务变更应通过 Yii 迁移；空库安装快照应与迁移版本保持一致。
