# 留言板接入与验收

维护人：D（秦东杰）。范围包括前台留言板、后台留言管理、话题热度图、移动端布局和校验。全站需求见[需求文档](需求文档.md)。

## 启动

按仓库 README 配置 PHP 8.3+、锁定依赖及 MySQL，在 `advanced/` 运行：

```bash
php yii migrate --interactive=0
php -S 127.0.0.1:8080 -t frontend/web
php -S 127.0.0.1:8081 -t backend/web
```

两条启动命令分开执行。前台和后台的入口均为 `index.php?r=message/index`，使用各自端口和会话。后台复用既有管理员角色和 `php yii access/grant-admin <已激活用户名>` 授权命令。既有数据库用迁移升级。当前 `data/install.sql` 是 B 阶段快照，全组集成后由组长重新导出正式 SQL。

## 数据与接口

新增业务表 `message`，当前全部迁移合计 12 张业务表。字段包含作者 ID、话题、纯文本正文、状态、创建时间及最近一次审核人和审核时间。状态为 `0` 待审核、`10` 已公开、`20` 已隐藏。

| 应用 | 路由 | 方法 | 行为 |
|---|---|---|---|
| 前台 | `message/index` | GET / HEAD | 已公开留言、提交表单入口、话题条数及占比 |
| 前台 | `message/create` | POST | 已登录成员提交。作者和初始状态由服务器确定 |
| 后台 | `message/index` | GET / HEAD | 管理员审核队列，支持 `status=pending/published/hidden/all` |
| 后台 | `message/publish`、`message/hide` | POST | 管理员处理留言，按原状态条件更新 |

## 验收操作

1. 以访客打开留言板，确认能浏览公开内容，表单处有登录和注册入口。
2. 在前台登录后提交有效留言。提交成功后页面反馈待审核，公开列表与图表保持原值。
3. 用后台管理员账号公开该留言。刷新前台后确认正文可见，切换条数及占比查看变化。
4. 从后台已公开列表隐藏留言，刷新前台，正文和计数同步移除。可以到已隐藏列表再次公开。
5. 分别在 390 像素和桌面宽度核对导航、表单、状态筛选和图表。短留言应出现校验提示。普通成员进入管理路由应被拒绝。
6. 在独立测试库运行 `php yii_test migrate --interactive=0`、`php vendor/bin/codecept build` 和 `php vendor/bin/codecept run --env php-builtin`。

## 2026 年 11 月 18 日验证

- 隔离环境使用 PHP 8.4.23 和 MariaDB 11.8.6。开发库和测试库从空库应用全部 7 项迁移。B 阶段安装快照另行导入并升级，执行 C、D 两项迁移后得到 12 张业务表，重复执行没有待迁移项。
- 全量 Codeception 通过 85 项测试、325 条断言。PHP 语法检查、PHPStan level 5、Yii 编码规范和 JavaScript 语法检查通过。
- Chromium 在 1440 与 390 像素宽度验证留言表单和管理队列，无横向溢出。实际操作覆盖登录、字数边界、提交、公开、键盘切换统计指标、隐藏和前台同步更新。
