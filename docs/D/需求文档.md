# 2026 世界杯主题团队主页

**南开大学 · 互联网数据库开发 · 项目需求文档（评审稿）**

王烨、阎科霖、赵非凡、秦东杰\
起草：秦东杰　｜　版本：v0.9　｜　日期：2026 年 11 月 18 日

## 一、项目目标与角色

网站面向课程展示和团队日常协作。访客可以从首页进入团队介绍、新闻公告、留言板和作业下载。小组成员通过各自账号参与交流，管理员在独立后台维护对外发布的内容。

| 角色 | 可进行的操作 |
|---|---|
| 访客 | 浏览公开页面、查看话题统计、下载已上传的作业、注册和登录 |
| 已激活成员 | 使用访客功能，并以自己的账号提交留言 |
| 管理员 | 登录后台，维护团队资料、新闻、分类和留言审核 |
| 部署维护者 | 管理数据库迁移、管理员授权、运行环境及提交材料 |

## 二、前台功能

| 编号 | 功能 | 需求 |
|---|---|---|
| F01 | 首页与导航 | 展示世界杯主题和团队简介，提供团队、成员、新闻、留言和作业下载入口。 |
| F02 | 团队与成员 | 展示已公开的团队资料、成员、职责、时间线及相关链接。成员详情通过独立页面访问。 |
| F03 | 新闻公告 | 展示已发布且当前可见的新闻，支持关键词、分类、标签筛选与分页。新闻详情显示正文和发布时间。 |
| F04 | 账号 | 提供注册、邮箱验证、登录、退出和密码重置。使用已激活账号提交留言。 |
| F05 | 作业下载 | 分别展示真实上传的团队和个人作业 ZIP，空目录显示空状态。 |
| F06 | 留言板 | 按从新到旧的顺序分页展示已公开的留言。每条包含用户名、话题、留言正文及提交时间。 |

## 三、后台维护与留言流程

| 编号 | 功能 | 需求 |
|---|---|---|
| B01 | 管理入口 | 独立后台仅向管理员开放内容管理。前后台分别维护登录会话。 |
| B02 | 团队维护 | 编辑团队介绍、成员、职责、项目节点及链接。管理员控制成员、节点与链接的公开状态。 |
| B03 | 新闻维护 | 支持编辑草稿、分类管理、发布、撤回、软删除及查看修改历史。 |
| B04 | 留言审核 | 支持按待审核、已公开、已隐藏和全部筛选。管理员可以公开或隐藏留言，隐藏后可以再次公开。 |

1. 已登录成员选择「赛事讨论」「团队交流」或「网站建议」，输入 5–500 字符。表单显示字数，校验失败时提示具体字段，保留有效输入。
2. 提交有效表单后，系统根据登录会话记录作者，将留言保存为待审核，并向提交者反馈结果。
3. 管理员从待审核列表查看正文和作者。管理员操作通过带 CSRF 令牌的 POST 提交，系统记录最后一次处理的管理员和时间。若操作时列表状态已变化，提示重新确认。
4. 公开后，留言进入前台列表和话题统计。隐藏后，前台列表和统计同步排除该留言，后台保留记录供复核。

### 动态图形 · 话题热度

留言板用条形图展示三个话题的公开留言数量。访客可在「条数」与「占比」之间切换，百分比的分母为全部已公开留言。数据为空时各话题显示零。图表显示文字数值并支持键盘操作，关闭脚本后仍可阅读条数。数据随页面刷新更新。

### 数据与界面约束

- 采用 PHP、Yii2 Advanced、MySQL、MVC 分层。数据库业务表数应超过 10 张。数据结构通过版本化迁移管理，并为最终交付导出安装 SQL。
- 公开页面只展示授权公开的内容，留言按纯文本输出。普通成员不能访问后台审核队列，邮箱和密码等账号资料不在留言页公开。
- 桌面和手机可完成浏览、填写表单、切换图表指标和后台审核。长正文换行，空列表和校验失败都提供明确反馈。

## 四、验收清单

| 编号 | 验收操作 | 预期 |
|---|---|---|
| T01 | 以访客访问首页、团队、新闻和作业下载 | 导航可用，仅显示对外内容，空数据有提示 |
| T02 | 用已激活成员登录，用访客或普通成员访问管理入口 | 前台成员可正常登录，未登录后台用户转到登录页，普通成员访问管理路由被拒绝 |
| T03 | 提交空白、少于 5 字符、超过 500 字符或非法话题的留言 | 页面显示对应错误，数据库无新留言 |
| T04 | 提交有效留言，依次公开、隐藏、再次公开 | 待审核时前台不可见。公开时列表和图表增加，隐藏时同步消失，再次公开后恢复 |
| T05 | 用 GET 或缺少有效 CSRF 令牌的 POST 请求执行审核 | 请求被拒绝，留言状态保持原值 |
| T06 | 在桌面和手机打开留言板，切换「条数／占比」 | 页面无横向溢出，数值、条形宽度与数据一致，可用键盘操作 |
| T07 | 在空库运行迁移并复核安装 SQL 和作业下载 | 业务表超过 10 张，正式 SQL 可用于还原，实际上传 ZIP 可通过页面下载 |
| T08 | 用管理员发布、撤回新闻并编辑公开成员资料 | 页面与后台状态一致，公开页面显示最新资料 |

### 团队交付

- 全组验收时汇总需求文档、设计文档、实现文档、用户手册、部署文档和展示 PPT，并核对团队包、个人作业 ZIP、安装 SQL、Git 记录与 Tower 任务记录。
- 需求文档正式文件名为 `队名_需求文档(学号1_学号2_学号3_学号4).pdf`。队名、学号按小组确认信息填写。
- 秦东杰负责留言板、留言管理、话题热度图、对应响应式样式、表单校验和本文。代码通过个人分支提交 PR，由组长评审。项目演示后，由组长按课程约定汇总并提交全组材料。

需求依据为小组《2026 世界杯主题团队主页》项目整体手册。
