## 本次首页更新

[桌面首屏](preview/cover.png) · [手机首屏](preview/mobile-cover.png)

首页采用独立的战报标题区和门前攻防照片。比赛双方、比分和进球时间取自赛事库；读者可以直接进入决赛详情。最近四场赛果和完整赛程入口紧随头条。桌面保留右侧快讯，手机将快讯放在赛果之后。没有公开新闻时，右栏标为“赛事档案精选”，标题链接到对应的站内战报。原来的冠军庆祝照片移到下方图文区。

在 390 × 844 视口，四张比分卡和完整赛程入口均在第一屏。Chromium 实测七种宽度、手机折叠菜单、作业下载、深浅色切换、新闻发布状态、组别与阶段筛选、加时和点球战报。回归通过 89 项测试、343 条断言。第二轮的原始首屏可在提交 `48b761d` 中对照。

## 第二轮实测

| 复审项 | 结果 |
|---|---|
| 首页 | 组长提供的冠军庆祝照片用于头图，其余三张现场照片用于下方消息卡。右侧快讯与下方预览读取公开新闻；不足三条时用赛事回顾补位，点击可进入对应的站内战报。 |
| 赛程与赛果 | 依据 Arena 的比赛行、比分卡、图文新闻三种版式，分别展示当地时间、双方国旗、场地和比分。完整档案可按小组或阶段筛选，覆盖 104 场比赛和 48 面旗帜。 |
| 数据还原 | 原始 JSON 转换为 cup_team、cup_match 两张表。新库跑迁移、旧库升级和直接还原 SQL 三条路径得到一致数据。逐场对照原始开球时间、半场、常规时间、加时、点球与进球记录。全库共 14 张业务表。 |
| 导航 | 顶部已移除“关于本站”“联系”和“赛事已收官 · 2026 典藏版”。赛程和战报均在本地打开，无 FIFA 外链。 |
| 浏览器 | 首页在 320、390、576、768、992、1200 和 1440 像素宽度无横向溢出。验证了手机菜单、组别与阶段筛选、决赛加时比分、点球战报和新闻详情跳转。 |
| 回归 | Codeception 单元与功能测试共 89 项、337 条断言通过。另以 Chromium 实跑留言提交、后台公开与隐藏、公开趋势统计。 |

执行环境为 Linux、PHP 8.4.23、MariaDB 11.8.6 和 headless Chromium。管理员审核入口为后台的 `index.php?r=message/index`。前后台继续使用独立登录会话。SQL 快照用于全新空库；已有数据库执行迁移升级。

1. **视觉复审。** 请重点查看桌面及手机头版，以及实际赛程行、赛果卡和下方消息预览。组长提供的图片已转 WebP，48 面国旗使用原 PNG。比赛库在迁移时导入；页面运行时从数据库读取。
