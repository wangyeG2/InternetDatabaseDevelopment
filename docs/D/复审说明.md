## 供组长决定

1. **头版与数据接口。** 现有首页只传团队资料。D 新增 DataController 复用 B 的公开新闻查询，无需修改 A/B/C 的控制器、模型或表结构。两场开幕赛、参赛足联和历届冠军使用静态赛事档案；每日留言趋势和话题统计来自数据库。
2. **Windows 部署。** 当前 main 的 tools/deploy-xampp.bat 第 13 行在 init 执行前检查 advanced/yii；该文件并未纳入 Git，全新检出会在这里提前退出。请 A 将前置检查改为已跟踪的 advanced/init。Windows 的 Composer 若通过 composer.bat 调用，第 53 行建议改为 call composer install --no-interaction，使后续建库和迁移继续执行。修改后请在干净的 XAMPP / PHP 8.2.12 实机验证。本分支遵守分工，未改 A 的脚本。
3. **团队材料。** 需求底稿覆盖六章，配套八张可编辑用例图。正式文件名待小组确认队名和四人的学号次序。data/personal 仍缺真实作业 ZIP。主分支团队资料和新闻缺省可为空，演示前应发布真实内容或明确标记示例。成员头像采用姓名首字占位。
4. **后台导航。** 后台审核路由已可直接访问。如需与“新闻管理”并列的导航项，请公共布局维护者在后台导航中加入“留言管理”。
