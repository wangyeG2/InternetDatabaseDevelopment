# 2026 世界杯主题团队主页

PHP + Yii2 Advanced + MySQL 课程项目。应用源码位于 `advanced/`，前台与后台分别使用其 `frontend/web`、`backend/web` 目录。

当前版本在组长基线上完成 B 的新闻公告模块及相关基础修复。先安装锁定依赖，再按[接入与运行说明](docs/B/接入与运行说明.md)配置数据库和启动应用。

- [B 文档索引](docs/B/README.md)：实现报告、设计图、数据字典、接口、测试和任务清单。
- `data/install.sql`：当前版本的空库安装快照；已有数据库使用 Yii 迁移升级。
- `data/team/B_news_source.zip`：团队源码下载包，配有 SHA256 校验文件。
- `data/personal/`：由各成员放入真实个人作业 ZIP，前台自动提供下载链接。

当前只有六张业务表，全组还需集成团队展示、留言板和动态图形等模块，达到至少十一张业务表后进行整体验收。当前本地交付及真实验证范围以 B 文档为准。
